# TFG: Desarrollo de un dispositivo de estimulación cognitiva y sensorial

Este repositorio contiene el código fuente, los bocetos de interfaces y los entornos de desarrollo utilizados para el diseño del dispositivo del Trabajo de Fin de Grado.

## 📁 Estructura del Repositorio
*   `/VS-...`: Archivos de desarrollo del juego principal y minijuegos secundarios creados en Visual Studio.
*   `TinkerCAD-...`: Código y circuito de simulación para la asociación de color y sonido.
*   `DartPad-...`: Bocetado y diseño de la interfaz de prueba.

## 🛠️ Tecnologías Utilizadas
*   **Entorno de desarrollo:** Visual Studio.
*   **Simulación electrónica:** TinkerCAD.
*   **Prototipado de interfaz:** DartPad (Flutter).
